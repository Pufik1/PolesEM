# Исправление ошибки при поступлении материалов от поставщиков

## Проблема
При работе с функцией поступления материалов от поставщиков возникала ошибка:
```
SQLSTATE[23000]: Integrity constraint violation: 1048 Column 'product_id' cannot be null
```

## Причина
Таблица `warehouse_operations` имела ограничение NOT NULL на колонке `product_id`, что не позволяло создавать записи для операций с материалами (где используется `material_id`, а `product_id` должен быть NULL).

## Решение

### 1. Изменения в базе данных
Выполните SQL-скрипт `/workspace/polesie_system/database_fix_warehouse_operations.sql`:

```bash
mysql -u root -p polesie_electromash < database_fix_warehouse_operations.sql
```

Этот скрипт:
- Делает колонку `product_id` nullable (NULL разрешён)
- Добавляет внешний ключ с ON DELETE SET NULL
- Проверяет наличие колонки `material_id` и добавляет её если нужно
- Создаёт индекс для `material_id`

### 2. Изменения в коде
Файл `/workspace/polesie_system/modules/warehouse/index.php` был обновлён:

- Убрана обязательная проверка `document_number` (теперь это поле необязательное)
- Добавлен try-catch блок для обработки ошибок транзакции
- Явно указывается `NULL` для `product_id` при создании операций с материалами
- Добавлены комментарии для важных мест кода

## Как работает функция поступления материалов

При поступлении материалов от поставщика создаются следующие записи:

1. **goods_receipt_documents** - документ приема (акт)
   - Номер вида: ПР-М-2024-001
   - Тип: from_supplier

2. **goods_receipt_items** - позиция документа приема
   - item_type: 'material'
   - product_id: NULL (важно!)
   - item_name, item_sku: данные из справочника материалов

3. **warehouse_operations** - операция склада
   - operation_type: 'income'
   - product_id: NULL (важно!)
   - material_id: ID материала
   - receipt_id: ссылка на документ приема

4. **material_stock_movements** - движение материалов
   - material_id: ID материала
   - operation_type: 'income'
   - quantity: количество

5. **materials** - обновление остатка
   - current_stock увеличивается на количество

## Проверка работы

1. Откройте модуль "Склад" → "Материалы"
2. Нажмите кнопку "Поступление материалов"
3. Выберите материал, укажите количество
4. Сохраните операцию
5. Должен успешно создаться документ и обновиться остаток

## Примечания

- Номер накладной поставщика (`document_number`) теперь необязательный
- Обязательно указывается только материал и количество
- Все операции выполняются в транзакции с откатом при ошибке
- Ошибки логируются в файл журнала
