# Реализация списка материалов (BOM) для продукции

## Описание решения

Для отображения списка материалов для каждого продукта в модальном окне (при нажатии на иконку "глаз") было принято решение хранить спецификацию материалов (Bill of Materials - BOM) непосредственно в таблице `products` в виде JSON.

## Почему JSON в products, а не отдельные таблицы?

1. **Простота**: Не нужно создавать сложные JOIN-запросы между таблицами
2. **Гибкость**: Легко добавлять/изменять материалы без изменения структуры БД
3. **Производительность**: Один запрос к таблице products вместо нескольких JOIN
4. **Удобство редактирования**: Можно легко обновлять через SQL UPDATE

## Изменения в базе данных

### 1. Добавлено поле bom_json в таблицу products

```sql
ALTER TABLE products 
ADD COLUMN bom_json JSON NULL COMMENT 'Список материалов для создания продукта (BOM)';
```

### 2. Миграция для заполнения BOM

Файл: `database_migrations_bom_json.sql`

Этот файл содержит:
- Добавление колонки `bom_json`
- Заполнение BOM для разных категорий продуктов:
  - **Чугунные изделия** (категории 1-2): чугун литейный, песок формовочный, кокс, ферросплавы
  - **Электродвигатели АИР** (категория 3): станина, сердечники, провод, подшипники, крепеж и т.д.
  - **Двигатели с повышенным скольжением AIRS** (категория 4): аналогично АИР но с усиленными компонентами
  - **Однофазные двигатели AIRE** (категория 5): + конденсатор, переключатель
  - **Для птицефабрик AIRP** (категория 6): нержавеющие компоненты, пищевая смазка
  - **Двухскоростные 2AIR** (категория 7): многоскоростной статор, переключатель скоростей
  - **Железнодорожные AIRCH** (категория 8): виброустойчивые компоненты
  - **Встраиваемые AIRV/AIRVS** (категории 9-10): безлаповая станина, фланец

## Структура BOM

Каждый продукт имеет массив материалов в формате:

```json
[
  {
    "material_id": 5,
    "name": "Станина (корпус) чугунная",
    "quantity": 1
  },
  {
    "material_id": 7,
    "name": "Провод медный обмоточный ПЭТВ-2",
    "quantity": 3.0
  }
]
```

Поля:
- `material_id`: ID материала (для связи с таблицей materials)
- `name`: Наименование материала (отображается в модальном окне)
- `quantity`: Количество в штуках (без единиц измерения типа кг, м)

## Изменения в коде

### modules/products/index.php

1. **AJAX обработчик** (строки ~149-162):
   - Читает `bom_json` из записи продукта
   - Декодирует JSON в массив
   - Возвращает в ответе вместе с данными продукта

2. **JavaScript функция renderProductModal** (строки ~937-961):
   - Отображает таблицу с материалами
   - Показывает номер, наименование и количество
   - Автоматически округляет количество до 2 знаков

## Как использовать

### Просмотр BOM в интерфейсе

1. Откройте страницу "Продукция" (`/modules/products/index.php`)
2. Нажмите на иконку "глаз" у любого продукта
3. В модальном окне появится секция "Материалы для производства (1 шт. продукта)"

### Обновление BOM для продукта

```sql
UPDATE products SET bom_json = JSON_ARRAY(
    JSON_OBJECT('material_id', 1, 'name', 'Материал 1', 'quantity', 5),
    JSON_OBJECT('material_id', 2, 'name', 'Материал 2', 'quantity', 10)
) WHERE id = PRODUCT_ID;
```

### Добавление нового материала в существующий BOM

```sql
UPDATE products SET bom_json = JSON_ARRAY_APPEND(
    bom_json,
    '$',
    JSON_OBJECT('material_id', 99, 'name', 'Новый материал', 'quantity', 1)
) WHERE id = PRODUCT_ID;
```

## Примечания

- Таблицы `product_bom` и `product_bom_items` больше не используются для отображения BOM в интерфейсе
- Старые данные из этих таблиц можно перенести в `bom_json` при необходимости
- Для 91 продукта автоматически созданы реалистичные списки материалов на основе их категории и характеристик
- Общее количество уникальных материалов в спецификациях: около 48 позиций
