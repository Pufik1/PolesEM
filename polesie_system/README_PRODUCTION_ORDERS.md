# Руководство по работе с заказами клиентов в производстве

## Обзор функционала

Вкладка "Заказы клиентов" в модуле "Производство" позволяет управлять производством продукции для конкретных заказов клиентов. 

### Основные возможности:

1. **Просмотр материалов для заказа** - возможность увидеть какие материалы и в каком количестве необходимы для производства продукции по заказу клиента
2. **Выдача материалов в производство** - выдача необходимых материалов со склада в производство с автоматическим списанием
3. **Завершение производства** - оприходование готовой продукции на склад после завершения производства

## Бизнес-процесс

### 1. Создание производственного заказа из заказа клиента

Когда клиент делает заказ и он оплачен, система автоматически показывает его во вкладке "Заказы клиентов" если:
- Заказ имеет статус "Оплачен"
- Для товаров заказа еще не создан производственный заказ ИЛИ производственный заказ находится в статусе "planned" или "in_progress"

### 2. Просмотр необходимых материалов

Для просмотра материалов необходимых для производства:
1. Нажмите кнопку **"Материалы"** в строке заказа
2. Откроется модальное окно со списком всех материалов из спецификации (BOM) продукта
3. В таблице отображается:
   - Наименование материала
   - Артикул
   - Наличие на складе
   - Требуемое количество (рассчитывается исходя из количества в заказе × норму расхода)
   - Уже выданное количество (если материалы ранее выдавались)
   - Количество к выдаче (можно редактировать)

### 3. Выдача материалов в производство

Процесс выдачи материалов:
1. В модальном окне просмотра материалов укажите количество каждого материала для выдачи
2. Нажмите кнопку **"Выдать материалы"**
3. Система:
   - Создаст производственный заказ (если еще не создан)
   - Запишет информацию о выданных материалах в таблицу `production_materials`
   - Спишет материалы со склада (уменьшит `current_stock` в таблице `materials`)
   - Обновит статус производственного заказа на "in_progress"

**Важно:** Материалы выдаются из наличия на складе. Если материала недостаточно, система выдаст ошибку.

### 4. Отслеживание выданных материалов

Во вкладке "Выдано в производство" можно посмотреть:
- Какие материалы были выданы в производство
- Сколько материалов уже использовано
- Сколько материалов доступно в производстве (выдано - использовано)

### 5. Завершение производства и оприходование на склад

Когда продукция произведена:
1. Нажмите кнопку **"Завершить"** в строке заказа (доступна когда статус "in_progress")
2. В модальном окне укажите:
   - Количество годных изделий
   - Количество брака (опционально)
   - Комментарий (опционально)
3. Нажмите **"Завершить"**
4. Система:
   - Оприходует годную продукцию на склад (увеличит `current_stock` в таблице `products`)
   - Обновит статус производственного заказа на "completed"
   - Обновит статус заказа клиента на "ready_for_shipment"
   - Создаст документ оприходования в таблице `production_completion_documents`

## Таблицы базы данных

### production_completion_documents
Хранит документы оприходования готовой продукции:
- `document_number` - номер документа
- `production_order_id` - ссылка на производственный заказ
- `product_id` - ID готового продукта
- `quantity` - количество годной продукции
- `defect_quantity` - количество брака
- `completion_date` - дата завершения
- `notes` - комментарий

### production_materials
Хранит информацию о выданных материалах:
- `production_order_id` - ссылка на производственный заказ
- `material_id` - ID материала
- `quantity_issued` - выданное количество
- `quantity_used` - использованное количество
- `quantity_returned` - возвращенное количество
- `status` - статус (issued, used, returned, partial)

## API Endpoints

### GET api.php?action=get_customer_order_materials&order_id={id}
Получение списка материалов для заказа клиента

**Ответ:**
```json
{
    "success": true,
    "order": { ... },
    "bom": { ... },
    "materials": [
        {
            "material_id": 1,
            "sku": "MAT-001",
            "material_name": "Сталь листовая",
            "unit": "кг",
            "warehouse_stock": 1000,
            "qty_per_unit": 5.5,
            "total_required": 55,
            "waste_percent": 2,
            "already_issued": 0,
            "to_issue": 55
        }
    ],
    "total_cost": 0
}
```

### POST api.php?action=issue_materials
Выдача материалов в производство

**Параметры:**
- `order_id` - ID заказа клиента
- `materials_data` - JSON массив материалов: `[{"material_id": 1, "quantity": 10}]`
- `notes` - комментарий (опционально)

**Ответ:**
```json
{
    "success": true,
    "message": "Материалы успешно выданы в производство",
    "production_order_id": 123
}
```

### POST api.php?action=complete_production
Завершение производства и оприходование на склад

**Параметры:**
- `production_order_id` - ID производственного заказа
- `quantity_completed` - количество годных изделий
- `quantity_defect` - количество брака (опционально)
- `notes` - комментарий (опционально)

**Ответ:**
```json
{
    "success": true,
    "message": "Продукция успешно оприходована на склад",
    "document_number": "PR-2024-00001"
}
```

## Миграции

Для работы функционала необходимо выполнить миграцию:
```bash
mysql -u username -p database_name < database_migrations_production_completion.sql
```

## Примечания

1. При выдаче материалов они списываются со склада немедленно
2. Готовая продукция оприходуется на склад только после нажатия кнопки "Завершить"
3. Брак не списывается автоматически - требуется дополнительная обработка
4. Система отслеживает уже выданные материалы чтобы избежать дублирования
