# Модуль "Пользователи" - ОАО "Полесьеэлектромаш"

## Описание
Модуль управления пользователями корпоративной ERP-системы предприятия.

## Функционал

### Основные возможности:
- **Просмотр списка всех пользователей** с информацией:
  - Логин, ФИО, Email, Телефон
  - Роль, Отдел, Должность
  - Статус (активен/неактивен)
  - Дата последнего входа
  
- **Создание нового пользователя** (только admin)
  - Обязательные поля: Логин, Пароль, ФИО, Email, Роль
  - Дополнительные: Телефон, Отдел, Должность
  - Статус активности
  
- **Редактирование пользователя** (только admin)
  - Изменение всех данных кроме логина
  - Смена пароля (опционально)
  - Назначение роли
  
- **Деактивация пользователя** (только admin)
  - Мягкое удаление (без удаления из БД)
  - Запрет на деактивацию текущего пользователя

### Права доступа:
- **admin** - полный доступ (создание, редактирование, деактивация)
- **director** - только просмотр списка пользователей
- Остальные роли - доступа нет

## Файлы модуля:
- `index.php` - основная страница модуля
- `get_user.php` - API для получения данных пользователя (AJAX)
- `README.md` - документация

## База данных
Используемые таблицы:
- `users` - пользователи системы
- `roles` - роли пользователей (7 ролей)

## URL доступа:
```
/modules/users/index.php
```

## Требования:
- Авторизация в системе обязательна
- PHP 7.4+
- MySQL 5.7+
- PDO extension

## Примечания:
- Пароли хранятся в открытом виде (согласно ТЗ)
- Ведется журнал активности (логирование всех действий)
- Используется AJAX для загрузки данных при редактировании
