# План производства - Описание функционала

## Обзор

Вкладка "План производства" предназначена для управления производственными заказами, отслеживания их статуса и контроля процесса производства от начала до завершения.

## Структура интерфейса

### 1. Карточки статусов производства

В верхней части вкладки расположены три карточки с реальной статистикой:
- **Запланировано** (желтая) - количество заказов в статусе "planned"
- **В производстве** (синяя) - количество заказов в статусе "in_progress"
- **Готово** (зеленая) - количество завершенных заказов

Счетчики обновляются динамически при фильтрации.

### 2. Фильтры

Для удобной навигации предусмотрены фильтры:
- **По статусу**: Все/Запланировано/В производстве/Готово/Отменено
- **По приоритету**: Все/Высокий/Нормальный/Низкий
- **Поиск**: по номеру заказа или названию продукта

### 3. Таблица производственных заказов

Отображает всю необходимую информацию:
- Номер производственного заказа
- Продукт (наименование + артикул)
- Количество к производству
- Статус (цветовой индикатор)
- Приоритет (с иконкой флага)
- Плановые даты начала и окончания
- Источник (заказ клиента или план)
- Кнопки действий

### 4. Кнопки действий

В зависимости от статуса заказа доступны разные действия:

#### Для статуса "Запланировано":
- **Начать** - переводит заказ в статус "В производстве"

#### Для статуса "В производстве":
- **Завершить** - открывает модальное окно для указания количества готовых изделий и брака

#### Для статуса "Готово":
- **Детали** - просмотр информации о завершении (в разработке)

## Интеграция с вкладкой "Заказы клиентов"

### Кнопка "Приступить к производству"

Во вкладке "Заказы клиентов" при просмотре материалов заказа появилась новая кнопка **"Приступить к производству"** (зеленая), которая:

1. **Отображается только когда все материалы выданы** в достаточном количестве
2. **Создает производственный заказ** если он еще не существует
3. **Автоматически запускает производство** переводя заказ в статус "in_progress"
4. **Перенаправляет на вкладку "План производства"** где можно отслеживать выполнение

### Логика работы

```
Заказ клиента (оплачен)
    ↓
Нажатие кнопки "Материалы"
    ↓
Проверка доступности материалов
    ↓
Если материалов достаточно → Показывается кнопка "Приступить к производству"
    ↓
Нажатие кнопки "Приступить к производству"
    ↓
Создание производственного заказа (если нет)
    ↓
Перевод в статус "in_progress"
    ↓
Заказ появляется во вкладке "План производства"
```

## API endpoints

### `start_production`
Перевод производственного заказа из статуса "planned" в "in_progress"

**Параметры:**
- `production_order_id` (POST) - ID производственного заказа

**Ответ:**
```json
{
    "success": true,
    "message": "Производство запущено"
}
```

### `create_production_order_from_customer`
Создание производственного заказа из заказа клиента с автоматическим запуском

**Параметры:**
- `order_id` (POST) - ID заказа клиента

**Ответ:**
```json
{
    "success": true,
    "message": "Производственный заказ создан и запущен в производство",
    "production_order_id": 123
}
```

## Жизненный цикл производственного заказа

1. **Planned (Запланировано)**
   - Заказ создан, но еще не начат
   - Ожидает доступности материалов и ресурсов
   - Доступно действие "Начать"

2. **In Progress (В производстве)**
   - Производство активно
   - Материалы выданы и используются
   - Доступно действие "Завершить"

3. **Completed (Готово)**
   - Производство завершено
   - Продукция оприходована на склад
   - Доступен просмотр деталей

4. **Cancelled (Отменено)**
   - Производство отменено
   - Требуется возврат материалов на склад

## Примечания

- Все производственные заказы автоматически попадают на вкладку после нажатия кнопки "Приступить к производству"
- Фильтрация работает на стороне клиента (JavaScript)
- Статистика обновляется динамически без перезагрузки страницы
- Для работы функционала требуется наличие таблицы `production_orders` в базе данных
