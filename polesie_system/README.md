# Инструкция по установке и запуску системы
# ОAO "Полесьеэлектромаш" - Корпоративная система управления

## Требования к окружению

- MAMP (Mac, Apache, MySQL, PHP)
- PHP версии 7.4 или выше
- MySQL версии 5.7 или выше
- Веб-браузер (Chrome, Firefox, Safari, Edge)

## Установка

### Шаг 1: Установка MAMP

1. Скачайте MAMP с официального сайта: https://www.mamp.info/
2. Установите MAMP в директорию по умолчанию
3. Запустите MAMP

### Шаг 2: Настройка MAMP

1. Откройте MAMP и нажмите "Preferences" (Настройки)
2. Перейдите на вкладку "Ports" и установите:
   - Apache: 8888
   - MySQL: 8889
3. Перейдите на вкладку "PHP" и выберите версию PHP 7.4 или выше
4. Нажмите OK

### Шаг 3: Импорт базы данных

1. Запустите сервера Apache и MySQL в MAMP (нажмите "Start Servers")
2. Откройте phpMyAdmin: http://localhost:8888/phpMyAdmin
3. Создайте новую базу данных с именем: `polesie_electromash`
4. Выберите созданную базу данных
5. Перейдите на вкладку "Импорт"
6. Выберите файл `database.sql` из папки проекта
7. Нажмите "Вперед" для импорта

### Шаг 4: Настройка конфигурации

1. Откройте файл `includes/config.php`
2. Проверьте параметры подключения к базе данных:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'polesie_electromash');
   define('DB_USER', 'root');
   define('DB_PASS', 'root'); // Пароль по умолчанию в MAMP
   ```
3. При необходимости измените пароль на ваш пароль MySQL

### Шаг 5: Размещение файлов проекта

1. Скопируйте папку `polesie_system` в папку htdocs MAMP
   - Путь по умолчанию: `/Applications/MAMP/htdocs/` (Mac)
   - Или: `C:\MAMP\htdocs\` (Windows)

### Шаг 6: Запуск системы

1. Откройте браузер
2. Перейдите по адресу: http://localhost:8888/polesie_system/
3. Вы увидите страницу авторизации

## Решение проблем

### Ошибка подключения к базе данных
- Проверьте, запущены ли сервера в MAMP
- Убедитесь, что имя базы данных указано верно
- Проверьте логин и пароль MySQL

### Страница не загружается
- Проверьте, что Apache запущен в MAMP
- Убедитесь, что порт 8888 не занят другим приложением
- Проверьте путь к файлам проекта

### Ошибки PHP
- Включите отображение ошибок в `includes/config.php`:
  ```php
  ini_set('display_errors', 1);
  error_reporting(E_ALL);
  ```
- Проверьте логи ошибок PHP в MAMP
